# Calculadora de Dimensionamento de Fio

Calculadora simples que sugere a bitola do fio e o disjuntor 
recomendado a partir da potência de um aparelho.

## Por que fiz esse projeto

Trabalhei como eletricista antes de migrar pra tecnologia, então 
resolvi juntar as duas coisas nesse projeto. Os valores de bitola 
e disjuntor vêm da tabela da NBR 5410 que eu já usava no dia a dia.

## Como funciona

- Informa a potência do aparelho (W) e a tensão (110V ou 220V)
- A calculadora converte pra corrente (I = P/V)
- Compara com uma tabela de referência e mostra a bitola e o disjuntor recomendados

## Tecnologias

HTML, CSS e JavaScript puro (sem framework).

## Importante

Cálculo de referência simplificado — não substitui a avaliação de 
um profissional habilitado.
